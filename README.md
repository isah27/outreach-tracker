# Local Outreach Tracker

Track prospects, outreach, follow-ups, replies, and status on your own computer. Data stays in this browser. Nothing is uploaded.

The app starts empty. It does not come with anyone else’s prospect list.

## How to use

1. Keep this whole `prospect-tracker` folder together.
2. Open `index.html` in Chrome, Edge, or Firefox (double-click it).
3. Add prospects with the form, or use **Import JSON** if you have a backup file.

## What you can do

- Click a row to open the side panel.
- Use **Add prospect** for a full form. Required fields are marked with a red `*`.
- Profile URLs are generated from the handle.
- Log outreach, follow-ups, and replies.
- Change status: Not contacted / In progress / Positive / Negative.
- Every save and status change gets a timestamp in the activity log.
- **Import JSON** loads a list from a `.json` file.
- **Export Excel** downloads two sheets: `Prospects` and `Activity`.
- **Reset data** clears this browser’s list.

## Notes

- Data does not sync across browsers or devices.
- Clearing site data or moving to another machine will lose entries unless you export first.
- Works offline. The Excel library is bundled in this folder.
